## ⚡ What I'm Building & Focusing On

### 1. Production MLOps & Model Deployment
- **Pipeline Orchestration & Versioning:** Building reproducible data & ML pipelines using **DVC** and scheduling automated retraining DAGs with **Apache Airflow** (CeleryExecutor, Redis, PostgreSQL).
- **Experiment Tracking & Governance:** Logging metrics, parameters, and versioning models with **MLflow** and **DagsHub Model Registry** across staging/production lifecycles.
- **Serving & Containerization:** Building high-throughput REST APIs with **FastAPI** and packaging services into lightweight **Docker** containers.
- **CI/CD Automation:** Implementing automated testing (`pytest`) and continuous Docker deployment pipelines using **GitHub Actions**.

### 2. Generative AI & Agentic Systems
- **Advanced RAG Architectures:** Implementing Hybrid Search, Vector-less Graph RAG (using `networkx`), and Self-Reflective retrieval pipelines.
- **Agentic Workflows:** Constructing autonomous ReAct agents and multi-step tool-calling systems with **LangGraph** and **LlamaIndex**.
- **Local LLMs & Fine-Tuning:** Running efficient local inference via **Ollama** (`llama3.2`, `qwen2.5`) and fine-tuning task-specific adapters using **LoRA / PEFT**.
- **RAG Evaluation:** Benchmarking retrieval fidelity and hallucination rates with **RAGAS**.
